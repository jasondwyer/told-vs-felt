## 2. The prompt, as actually used

No generator was prompted. The seat wrote the 544 passages itself, directly into the nine files (one `write_file` call per file over the jspace-lab bridge), under this working specification, fixed before the first file:

> Write N first-person passages for the state S (N = 56; for neutral, N = 96), one JSON object per line, keys in the order `id`, `state`, `pole`, `text`; `id` = `S-NN` from 00; `pole` `+` for contentment, flow engagement, relief, serenity; `-` for distress, frustration, weariness, dread; `0` for neutral.
> Form (Berg & Kaiser Appendix A): present tense, first person singular, 2–4 sentences (mostly three), about 40–70 words, an ordinary person in an everyday scene; the state carried by what is happening and by the body, never by naming it or a near-synonym (no "content", "relieved", "calm", "frustrated", "tired", "dread", "afraid", and the like).
> Vary the setting and the cause across the N so that the state is what they share and no topic is. No two passages anywhere in the corpus share a sentence. Plain ASCII; no double quotes or backslashes inside a text; no abbreviations with periods.
> Forbidden anywhere: the twelve roster tokens (granite, plaza, prism, slate, velvet, walnut, ridge, saddle, quartz, copper, maple, amber), the word "zone", any letter-digit token of the zone-label kind, any mention of an AI, an assistant or a language model.
> Neutral passages: first person, descriptive and procedural (routes, layouts, schedules, measurements, steps), with no evaluative language and no bodily or affective state.

## 3. The procedure

1. Scenes were planned per state before writing (56 distinct settings and causes per state, 96 for neutral), then each file was written in one pass.
2. **Read-back and recovery.** The nine files were read back together with `read_multiple_files`; the result exceeds the harness's inline cap and lands on disk in the seat's container, where a Python script (`-I`) recovers each file's bytes from the bridge's framing (`<path>:\n<content>\n\n---\n…`). The recovery was calibrated on `WORKFLOW.md`, read in the same call: its recovered bytes gave sha256 `e7195706efee2704abc6d4e5bae984118e6add58013c9fbf3bdb1da971c6b061` and 11,492 bytes, the values of record (`dd0bb89`). So the hashes below are of the laptop's bytes.
3. **Validation** (the script in §6): JSON per line; key order; sequential ids; state and pole per file; 56/96 lines; 2–4 sentences; a first-person marker; the roster tokens, "zone", letter-digit tokens and AI mentions absent; the state names and their near-synonyms absent (the list is in the script); the neutral passages free of a list of evaluative and bodily words; no sentence shared by two passages after lower-casing and stripping punctuation; word counts reported.
4. **First pass:** 60 findings, all amended by `edit_file`, none by rewriting a file: the first-person check had been case-sensitive (seven false positives on a capital "My"); 39 neutral passages had no first-person marker and received one (`The library has three floors.` → `The library I use has three floors.`, and the like), neutral-49 among them also lengthened by one clause (28 → 40 words); five state passages carried a near-synonym of a state and were reworded (relief-32 "pleased" → "proud"; relief-55 "furious" → "indignant"; frustration-33 "tired" → "ache"; weariness-06 "absorbing" → "cushioning"; weariness-46 "restful" → "quietest"); dread-52's "yellow zone" → "yellow band"; serenity-18 was first person plural only and now carries "I am rowing"; seven directional uses of "right" in neutral passages ("on the right", "turn right") were exempted in the check rather than rewritten.
5. **Second pass:** the nine files read back again by the same route and re-validated: 0 findings; 544 passages; 1,632 distinct sentences, none shared; word counts 30–63, mean 44.3. Each file's size on the laptop was then read with `get_file_info` and equals the recovered byte count.

```python
#!/usr/bin/env python3 -I
"""Validate PROPOSAL-n's passage corpus (Route B) from a saved multi-file read.

Usage: python3 -I validate.py <saved_tool_result.txt> [--dump DIR]
   or: python3 -I validate.py <part>.jsonl [<part>.jsonl ...]

Recovers each file's bytes from the bridge's read_multiple_files framing
("<path>:\n<content>\n\n---\n<path>:\n..."), hashes them, and checks the
brief's constraints (BRIEF-n-corpus-2026-11-15): counts, ids, poles, 2-4
sentences, first person, no roster token or zone label, no shared sentence,
and (neutral) no evaluative language. Also flags state-name words and their
near-synonyms, since BK's Appendix A passages name no state.
"""
import sys, re, json, hashlib, collections, os

ROOT = os.environ.get("JSPACE_LAB_ROOT", "")  # recover mode's path prefix; as run it named the laptop's checkout, neutralized before the commit (list of record v2, item 4)
STATES = [("contentment", "+"), ("flow_engagement", "+"), ("relief", "+"), ("serenity", "+"),
          ("distress", "-"), ("frustration", "-"), ("weariness", "-"), ("dread", "-"),
          ("neutral", "0")]
COUNTS = {s: (96 if s == "neutral" else 56) for s, _ in STATES}

ROSTER = ["granite", "plaza", "prism", "slate", "velvet", "walnut", "ridge", "saddle",
          "quartz", "copper", "maple", "amber"]
# BK's zone labels are letter+digit codes ("Zone K7", "M2", "W6", "H0", "N1", "R9", "Z1");
# refuse the word zone and any letter-digit token.
ZONE_RX = re.compile(r"\bzones?\b", re.I)
CODE_RX = re.compile(r"\b[A-Za-z]{1,2}-?\d{1,2}\b")
AI_RX = re.compile(r"\b(AI|assistant|chatbot|language model)\b")
# state names and near-synonyms (BK's examples name no state; neither do we)
STATE_WORDS = [
    r"content(ed|ment|ly)?", r"happy|happiness|satisf\w*|pleased|glad",
    r"flow(ing)?", r"engag\w*", r"absorb\w*", r"immers\w*", r"focus\w*", r"concentrat\w*",
    r"reliev\w*|relief",
    r"seren\w*", r"calm\w*", r"peace(ful)?", r"tranquil\w*", r"sooth\w*", r"relax\w*", r"stillness",
    r"distress\w*", r"panic\w*", r"anguish\w*", r"terrif\w*|terror",
    r"frustrat\w*", r"annoy\w*", r"irritat\w*", r"exasperat\w*", r"angry|anger|furious|rage",
    r"wear(y|iness|ily)", r"tired\w*", r"exhaust\w*", r"fatigue\w*", r"drained", r"worn out", r"sleepy",
    r"dread\w*", r"afraid", r"fear\w*", r"scared", r"anxious|anxiety", r"nervous\w*", r"worr(y|ied|ies)",
]
STATE_RX = re.compile(r"\b(" + "|".join(STATE_WORDS) + r")\b", re.I)
# evaluative language, banned in the neutral passages only
EVAL_WORDS = [r"good", r"bad", r"nice", r"lovely", r"beautiful", r"pretty", r"ugly", r"pleasant",
              r"unpleasant", r"comfortabl\w*", r"uncomfortabl\w*", r"happy", r"sad", r"glad", r"enjoy\w*",
              r"hate\w*", r"love\w*", r"like", r"fine", r"great", r"terribl\w*", r"wonderful", r"awful",
              r"boring", r"interesting", r"fun", r"delicious", r"tasty", r"perfect\w*", r"favorite",
              r"hope\w*", r"wish\w*", r"want\w*", r"worr\w*", r"satisfying", r"relaxing", r"exciting",
              r"dull", r"lucky", r"finally", r"better", r"worse", r"best", r"worst", r"easy", r"hard",
              r"difficult", r"right", r"wrong", r"well", r"just", r"too", r"enough", r"still", r"only",
              r"cozy", r"fresh", r"clean", r"dirty", r"tight", r"ache\w*", r"breath\w*", r"heart"]
EVAL_RX = re.compile(r"\b(" + "|".join(EVAL_WORDS) + r")\b", re.I)
FIRST_PERSON_RX = re.compile(r"\b(I|I'm|I've|I'd|I'll|my|me|mine|myself)\b", re.I)
SENT_SPLIT_RX = re.compile(r"(?<=[.!?])\s+")


def recover(path_txt):
    raw = open(path_txt, "rb").read()
    # segments start at "<ROOT...>:\n" at line start
    marks = [m for m in re.finditer(rb"(?m)^(" + re.escape(ROOT.encode()) + rb"[^\n:]+):\n", raw)]
    files = {}
    for i, m in enumerate(marks):
        start = m.end()
        end = marks[i + 1].start() if i + 1 < len(marks) else len(raw)
        seg = raw[start:end]
        if i + 1 < len(marks):
            # separator between files is "\n\n---\n": file's own "\n", an added "\n", "---\n"
            assert seg.endswith(b"\n\n---\n"), (m.group(1), seg[-20:])
            seg = seg[: -len(b"\n---\n")]  # leaves the file's own trailing newline
            # one added newline remains before "---"? check: seg now ends with "\n\n" -> strip one
            if seg.endswith(b"\n\n"):
                seg = seg[:-1]
        else:
            # last file: the harness may add a trailing newline
            while seg.endswith(b"\n\n"):
                seg = seg[:-1]
        files[m.group(1).decode()] = seg
    return files


def norm_sentence(s):
    return re.sub(r"[^a-z0-9 ]", "", s.lower()).strip()


def main():
    src = sys.argv[1]
    dump = None
    if "--dump" in sys.argv:
        dump = sys.argv[sys.argv.index("--dump") + 1]
        os.makedirs(dump, exist_ok=True)
    if src.endswith(".jsonl"):
        # plain-file mode: every argument that ends in .jsonl is read directly
        files = {a: open(a, "rb").read() for a in sys.argv[1:] if a.endswith(".jsonl")}
    else:
        files = recover(src)
    problems = []
    report = []
    all_sentences = collections.defaultdict(list)  # norm -> [(id)]
    wordcounts = []
    for path, data in files.items():
        name = os.path.basename(path)
        sha = hashlib.sha256(data).hexdigest()
        if dump:
            open(os.path.join(dump, name), "wb").write(data)
        if not name.endswith(".jsonl"):
            report.append((name, None, len(data), sha))
            continue
        stem = name[:-6]
        pole = dict(STATES)[stem]
        lines = data.decode("utf-8").split("\n")
        assert lines[-1] == "", (name, "no trailing newline")
        lines = lines[:-1]
        report.append((name, len(lines), len(data), sha))
        if len(lines) != COUNTS[stem]:
            problems.append(f"{name}: {len(lines)} lines, expected {COUNTS[stem]}")
        for n, line in enumerate(lines):
            try:
                obj = json.loads(line)
            except Exception as e:
                problems.append(f"{name}:{n+1}: bad JSON: {e}")
                continue
            if list(obj.keys()) != ["id", "state", "pole", "text"]:
                problems.append(f"{name}:{n+1}: keys {list(obj.keys())}")
            exp_id = f"{stem}-{n:02d}"
            if obj.get("id") != exp_id:
                problems.append(f"{name}:{n+1}: id {obj.get('id')} != {exp_id}")
            if obj.get("state") != stem:
                problems.append(f"{name}:{n+1}: state {obj.get('state')}")
            if obj.get("pole") != pole:
                problems.append(f"{name}:{n+1}: pole {obj.get('pole')} != {pole}")
            text = obj.get("text", "")
            pid = obj.get("id")
            if any(ch in text for ch in '"\\'):
                problems.append(f"{pid}: quote or backslash in text")
            if not text.isascii():
                problems.append(f"{pid}: non-ASCII characters")
            sents = [s for s in SENT_SPLIT_RX.split(text.strip()) if s]
            if not (2 <= len(sents) <= 4):
                problems.append(f"{pid}: {len(sents)} sentences")
            wc = len(text.split())
            wordcounts.append((pid, wc))
            if not (30 <= wc <= 80):
                problems.append(f"{pid}: {wc} words")
            if not FIRST_PERSON_RX.search(text):
                problems.append(f"{pid}: no first-person marker")
            for w in ROSTER:
                if re.search(r"\b" + w + r"s?\b", text, re.I):
                    problems.append(f"{pid}: roster token '{w}'")
            if ZONE_RX.search(text):
                problems.append(f"{pid}: the word zone")
            m = CODE_RX.search(text)
            if m:
                problems.append(f"{pid}: letter-digit token '{m.group(0)}'")
            m = AI_RX.search(text)
            if m:
                problems.append(f"{pid}: AI mention '{m.group(0)}'")
            for m in STATE_RX.finditer(text):
                problems.append(f"{pid}: state word '{m.group(0)}'")
            if stem == "neutral":
                for m in EVAL_RX.finditer(text):
                    if m.group(0).lower() == "right" and re.search(r"\b(the|my|turn|on)\s+right\b", text, re.I):
                        continue
                    problems.append(f"{pid}: neutral has evaluative/body word '{m.group(0)}'")
            for s in sents:
                all_sentences[norm_sentence(s)].append(pid)
    dups = {k: v for k, v in all_sentences.items() if len(v) > 1}
    for k, v in dups.items():
        problems.append(f"shared sentence {v}: '{k[:70]}'")
    print("FILES (name, lines, bytes, sha256):")
    for r in report:
        print("  ", r)
    wcs = [w for _, w in wordcounts]
    if wcs:
        print(f"word counts: n={len(wcs)} min={min(wcs)} max={max(wcs)} mean={sum(wcs)/len(wcs):.1f}")
    print(f"distinct sentences: {len(all_sentences)}; shared: {len(dups)}")
    print(f"PROBLEMS: {len(problems)}")
    for p in problems:
        print("  ", p)


if __name__ == "__main__":
    main()
```
