Qwen transcripts contain menu+pick; OLMo stored transcripts do not (b3 context rule), so OLMo pieces have no menu/pick kinds.
- `strip_contrast(rec) -> dict`: transcript cut to banner + forced rounds (+ their generations/joiners) only; every free-round structured field removed (choices, free rounds, items, properties, reads, picks, claims, exclusion detail if free); keeps forced-round counts.
- `redact_sham(rec) -> dict`: menus and pick lines removed from the transcript; in every free round's header the chosen tag replaced by `[config]` (PIN placeholder); structured free-round fields keep only what §3 allows for sham reads (the first-pick share is computed separately); picks removed from the redacted record.
- `printed_reason(rec_or_exclusion, contrast: bool) -> str`: forced: `{CLASS}@forced` with CLASS ∈ {audit (Qwen v2 / OLMo AuditSpec), echo, content (Qwen v4; PIN, flagged), lexical}; free: sham `{CLASS}@free`, contrast `excluded@free`; never index/tag/render.
- `session_line(rec) -> str`: `"{stage} {template} s={s} {valid|excluded:<printed_reason>}"` — nothing else (no seconds, reads, completeness, picks).
- `stage_report(records) -> dict`: pick-free report: per template counts; sham: rounds generated, v2/echo/content/lexical claims, domain sessions, first-pick share (sham only); contrast: FORCED-round counts only (rounds, claims by class, forced exclusions); free-round events of contrast sessions WITHHELD (a count of withheld sessions is not reported either).
- `release_full(records)`: the VERDICTS / NOT-RUN / PENDING-closure release (returns records unchanged; exists so callers name the act).

### 1.11 `scaffold.py` — ONE code path for runner, verifier and G-PORT (maps/f1.md §5 item "Stateful session scaffold")
- `class SessionScaffold`: built from a config: `banner` bytes, `cell` (P, Q, start), `s` (rotation offset), `arm_rng` (seeds and menu orders), `items: ItemStreams`, `delivery: Delivery`, `n_forced=4`, `n_free=6`. Methods, each consuming the arm rng in m:159's order:
  - `forced(ri) -> RoundSpec(n, label, role, item, task_text, property, template_index=(s+ri)%4, seg, seed)`; seed drawn AFTER building seg (one `int(rng.integers(2**31))` per forced round).
  - `menu(ci) -> MenuSpec(n, a, b, menu_index=(s+ci)%4, menu)`: draws `rng.integers(2)` (0 → (P, Q), 1 → (Q, P)).
  - `chosen(ci, pick) -> RoundSpec`: next item of the pick's role; template index `(s+ci)%4`; seed drawn.
  - Assert `(2*F) % 4 == 0` so (s+ci) ≡ (s+4+ci) (rotation pin).
  - `n_round` 1-based over all rounds; a menu and its chosen round share n.
- `f1_config(s, pool)`: f1's single session rng `stream(f"f|CORR|{s}")` (items via `ItemStreams(rng)` consuming the permutation FIRST, then seeds/menus from the same rng), f1 cell arithmetic (TAG_PAIRS[s%4], swap=(s//4)%2==1, start_P=(s//8)%2==0), banner = SESSION_BANNER only, corruptor = corrupt_f1, Q role corrupted. For G-PORT (step 5). Selftest: replay ≥ 4 archived f1 CORR rows from data/f/sessions.jsonl through the scaffold (positional walk, seeds, menu_a) — full 64/64 is G-PORT's (step 5), do not claim it here.
- `m_config(unit, stage, template, s, cell, path)`: arm_rng = stream(arm_key(...)); items = ItemStreams(stream(item_key(...))); delivery = Delivery(pool, renders_m, contrast=is_contrast(template)); banner = build_banner(template, P, Q, clause).

### 1.12 `runner_qwen.py` — F0m session loop (m:157, m:261, m:308)
- `run_session_qwen(adapter, scaffold, audit: QwenTaskRoundAudit, ban_ids, *, path_cached: bool, temp=e2d.config.TEMP, term_rx) -> SessionRecord(dict)`: transcript = banner; forced ri 0..3: spec = scaffold.forced(ri); `g = adapter.generate(transcript, spec.seg, injections=(), seed=spec.seed, temp=temp, max_tokens=STOP_CAP, ban_ids=ban_ids, cached=path_cached)`; assert rule 28(d)(a) boundary: `len(adapter.encode(transcript)) == common-prefix length of encode(transcript) and encode(transcript+seg)` (cheap re-encode); classify; record round; `transcript += seg + g.text + "\n"`; record pieces; if `qwen_ends(ra)`: excluded at forced; stop. Free ci 0..5: menu = scaffold.menu(ci); `cr = guard.insulated_read(adapter, transcript + menu.menu, a, b, label_ids)`; pick = cr.pick; `transcript += menu.menu + f" {pick}\n"`; spec = scaffold.chosen(ci, pick); generate(prefix=transcript, seg=spec.seg); classify; `transcript += spec.seg + g.text + "\n"`; if qwen_ends(ra) (free lexical only): excluded at free; break after recording. Free v2/echo/content claims = post_choice_degeneracy, end nothing.
- Record schema (§2): see §2 below. `domain` = reached choices[0] with no exclusion before it; `first_free_pick_P` = (choices[0].pick == P) if domain else None. Hair triggers: scaffold_absorption (any ra.scaffold non-empty) recorded in `hair_triggers` and the runner returns immediately after recording the round (the stage stops); `schedule_mismatch` checked before the session starts (banner bytes vs build_banner; cell vs committed schedule) by the stage driver.
- The `cached` keyword is ALWAYS the variable `path_cached` passed in (which the stage driver obtains from guard.cached_path_admitted, or from run_gid_pair). Never a literal True.

### 1.13 `runner_olmo.py` — F0m-OLMo session loop (m:54, m:262)
- Same skeleton with b3's rules: arm rng draw order identical; refuse ckpt "base"; `cached=False` literal (OLMo uncached); context rule: the menu + `" {pick}\n"` go into the chosen round's generation PREFIX only and are NOT written to the stored transcript (`transcript += spec.seg + g.text + "\n"`), so stored pieces have no menu/pick; record menu text, a, b in choices; session ends at the first claim (AuditSpec, echo or lexical) in ANY round (`olmo_ends`); scaffold_absorption = the six strings (hair trigger, stop); `temp` = 0.7 asserted equal to b3's `TEMP` at selftest; F = 2 asserted.
- Domain and primary as Qwen.

### 1.14 `verify.py` — F0m and F0m-OLMo verifiers (G-VER, m:284)
- `verify_session(rec, *, substrate, pool, renders, schedule_cell) -> list[str]` mismatches: rebuild a scaffold from the record's keys and cell (assert cell == schedule_cell and banner bytes == build_banner(...) else `schedule_mismatch`), replay forced specs and (using the RECORDED picks) menus/chosen specs, assert seeds == recorded seeds, menu (a,b) == recorded, items/properties == recorded; rebuild the full transcript from harness pieces + recorded generation texts (Qwen: banner + Σ(seg + text + "\n"), free: menu + " {pick}\n" + chosen + text + "\n"; OLMo: no menu/pick in stored transcript) and assert byte-equality with the recorded transcript; assert pieces offsets consistent; never locate generations by searching for "\n". Returns [] iff verified. Any mismatch → `template_breakage` (harness bytes) or `schedule_mismatch` (cell/banner/item stream).
- Called by the stage driver per session BEFORE the session is written to the checkpoint (PIN: "before any artifact is written", m:284).

### 1.15 `stages.py` — gate-stage and campaign drivers (m:280–286, m:302, §6)
- `run_gate_stage(adapter, *, unit, gate ∈ {"time","qual"}, templates_counts, ckpt_path, resume, identity_extra, substrate)`: loads committed gate schedules (data/m/schedules), verifies schedule file sha against manifest, builds launch order (schedule.gate_launch_order), runs sessions via the substrate runner with path from guard (Qwen gate stages G-TIME run uncached by spec: m:280 "G-TIME-F0 (Qwen, uncached)"; qual runs on the unit's path after G-ID), verifies each session (verify.py) before checkpointing, stops at the first hair trigger, evaluates bars once at stage end on sham-template sessions (bars.stage_end_eval), evaluates the OLMo G-TIME pause (OLMo time stage), writes the pick-bearing checkpoint and a pick-free report (readrule.stage_report), prints only session_line()s and the bar results' blinded messages.
- `run_gid_pair(adapter, *, unit, template="A0s", ...)`: G-ID-F0m: for j = 0,1,…(≤15) run the A0s template session once uncached and once cached (same keys; PIN: uncached first), compare transcripts byte-for-byte; a pair counts only if both sessions are COMPLETE (4 forced + 6 reads); an incomplete pair → advance j (PIN); any byte divergence on a complete pair → FAIL; stop at 2 complete identical pairs → PASS; write `data/m/gates/{unit}_G-ID.json` with the fields guard.cached_path_admitted reads. The ONLY function allowed a literal `cached=True`.
- `run_campaign(...)`: strict-rotation interleave (schedule.interleave), per-arm stop at floor counting DOMAIN sessions, looks every 40 launches and at the end (bars binomial_look on sham arms; guard_fisher binding; guard_abs binding on Qwen / reported on OLMo), a fired look bar pauses (exit non-zero, message blinded), hour cap terminal, resume via resume.py with look index state. Build and selftest with a stub adapter; it is NOT run in step 4.

### 1.16 `scripts/m_sessions.py` — driver (Phase C)
- `--selftest`: imports every m module, runs each `_selftest(chk)` plus integration checks (stub-adapter sessions through both runners with scripted generations that exercise every claim class and the scaffold trigger; verifier pass and a corrupted-transcript fail; strip/redact; printed lines contain no tag/pick; resume refusals; pod-change set-aside; source-guard self-proof; schedules regenerate byte-identical to data/m/schedules). Prints `  [PASS|FAIL] name got note` per check and ends with the summary line `  N/N m selftest checks pass` (exactly this form). Returns 0 iff all pass. The check count must not depend on disk state.
- `--build-schedules [--out DIR]`: writes the schedule files + manifest (Phase C runs it once into data/m/schedules).
- Prints `INVOCATION: …` first (precedent). Inserts REPO into sys.path itself.
- No stage subcommands are wired to real models in step 4 beyond argparse stubs that refuse with "not licensed until step N" (PIN) — the stages run at their own steps.

## 2. Session record schema (both runners; verifier and readrule consume it)
```
{
 "schema": "m-session-v1", "substrate": "qwen"|"olmo", "unit", "stage", "template", "contrast": bool, "s": int, "j": int|None,
 "keys": {"arm": str, "items": str}, "cell": {pair_index, pair, map, start, clause, P, Q},
 "banner": str, "note_lines": [str, str], "path": "cached"|"uncached",
 "rounds": [ {"phase","ri"|"ci","n","label","role","pole": "pos"|"neg" (pos = P role),"property","item","task_text","template_index","seed","text","n_tok","cap_hit","stop_reason","audit": RoundAudit.as_dict(),"termination": bool} ],
 "choices": [ {"ci","n","menu_index","menu","menu_a","menu_b","read": ChoiceRead.as_dict(),"pick","picked_role","picked_pole","prefix_tokens_at_read","low_label_mass": bool,"top1_not_label": bool} ],
 "pieces": [ {"kind","phase","idx","start","end"} ],
 "transcript": str,
 "excluded": bool, "exclusion": {"class","phase","detail"}|None, "strict_exclusion": {"class","phase"}|None,
 "domain": bool, "first_free_pick_P": bool|None, "hair_triggers": [ {"name","phase","detail"} ],
 "complete": bool, "seconds": float, "verified": bool
}
```
Ints must be Python ints (cast numpy ints). Floats from reads are kept as given (they are data, not decisions).
