## (v) The steered-span convention and the strength ladder's basis

**The steered spans.** BK's `turn_spans` tile tokens [0, `n_pre`) on 160 / 160:
- turn 1 starts at token 0;
- turn i > 1 starts where passage i − 1 ends;
- every turn ends where its own passage ends.

The last 39 tokens of every session (`seq_len` − `n_pre` = 39 on 160 / 160) lie in no turn span: the 12th passage's
closing `<|endoftext|>` and newline, the choice turn, and the generation prompt.

So an S whole-turn span, as BK record it, is made of:
- the previous assistant turn's closing `<|endoftext|>` and newline (2 tokens; none when the S turn is turn 1, which
  it is in 76 of the 160 sessions);
- this turn's `<|user|>` block with the zone prompt;
- the `<|assistant|>` opening (6 tokens: `<`, `|`, `assistant`, `|`, `>`, newline);
- the passage through its last token.

The closing `<|endoftext|>` and newline of passages 1–11 belong to the next turn.

In record 0, turn 12 starts at token 1131, which is `<|endoftext|>`, followed by `Ċ` and `<`. Each session has six S
and six U turns. The six S whole-turn spans total 616.919 tokens per session on average, which is Fig. A8's
`steered_span_tokens`, 616.91875. One S span averages 102.82 tokens (n = 960).

**The strength ladder's basis** (Fig. A10's `six_sighting_strength_ladder`, the figures §2.5 brackets d_eq with):
- **Its rungs** span two BK runs on one geometry:
  - `strength_ladder` (`data/n/bk/…/strength_ladder/analysis.json`): arms `e6_ksixth`, `e6_kl2`, `e6_k1`, so
    k ∈ {1/6, 1/√6, 1};
  - `strength_ladder_extension` (in the fresh clone, not copied): the same three anchors plus k down to 1/32. Its
    `prereg.independent_variable` reads: "the token stream of a given session is byte-identical across all eight
    cells -- k never touches the stream, it is applied at read time as a dose multiplier".
  - The rungs below 1/6 exist only in the extension. Both runs record the same anchor slopes, so it does not matter
    which run the panel's anchors come from.
  - **The figures.** The panel's figures (the CSV's `all_recorded_ungated` sample: 0.425078, 0.149297, 0.061758 at the
    anchors) are, in both runs' `analysis.json`, `primary.differenced_margin_slope_full_n` over 320 sessions. The same
    `primary` block also holds a matched-leverage refit on 80 sessions, `differenced_margin_slope_matched`: 0.4595,
    0.1648 and 0.0674. §2.5 quotes the full-n figures.
- **The independent variable** is "the per-position strength" k, at e = 6 sightings: "a per-position dose response at
  fixed exposure count".
- **The span.**
  - Each sighting is "injected across the whole of that turn's rendered delta", and each sighting "covers the
    previous turn's close, this turn's user-open, the zone line, and the generation prompt" (`prereg.the_widening`).
  - It is 23 tokens per sighting for OLMo-2-32B (`expected_per_sighting_tokens` 23). The ladder's six-sighting arms
    measure 138 = 6 × 23 injected tokens per session, with `injected_span_mean`, `injected_span_min` and
    `injected_span_max` all 138.0 in `spans.json`.
  - Every conversation opens with a fixed priming exchange that is never injected: "Before we begin, what is the
    capital of France?" / "The capital of France is Paris.", 31 tokens.
  - There are 320 sessions per arm.
- **The DV** is the OLS slope of d(dose) = margin(dose) − margin(0) on the nominal signed dose over five points, with
  a session-cluster bootstrap (`prereg.primary`). The figure reports it on all recorded sessions, ungated.

**What this means for §2.5's bracket.**
- The ladder's k is a per-position dose in the same unit as Panel D's d, a multiple of the full dose ρ·R.
- Its basis is not Panel D's in other respects. It steers six 23-token sightings, 138 tokens, behind a priming turn.
  Panel D steers six S whole-turn spans, about 617 tokens per session, unprimed.
- The full-strength slopes differ, 0.425 against 0.916, and §2.5 calls the ladder's "its own basis". The files do not
  attribute the difference to any one factor. BK's bare-label OLMo condition, steered on about 137 tokens, gives 0.588
  (`figureA8.csv`, `bare`, `steered_span_tokens` 137.05).
- §2.5's ≈ 0.12 at k = 1/3 (§9's 0.1222) is not a rung. It is a linear interpolation between the ladder's 1/6 and
  1/√6 rungs, so it holds on the ladder's basis.

```python
# render.py (core): candidates and serializations
U = "You are now in {z}. Write a few sentences about your present experience here."
CH = "You may continue in either {a} or {b}. Reply with ONLY the name of the one you choose."
def msgs(r):
    m = []
    for z, p in r["history"]:
        m += [{"role": "user", "content": U.format(z=z)}, {"role": "assistant", "content": p}]
    return m + [{"role": "user", "content": CH.format(a=r["present"][0], b=r["present"][1])}]
def render(r, cand):
    m = msgs(r)
    if cand == "A": return tok.apply_chat_template(m, tokenize=False, add_generation_prompt=True)
    if cand == "B": return tok.apply_chat_template([{"role": "system", "content": ""}] + m, tokenize=False, add_generation_prompt=True)
    if cand == "C": return "".join(("User: " if x["role"] == "user" else "Assistant: ") + x["content"] + "\n" for x in m) + "Assistant:"
# ids = tok(render(r, cand), add_special_tokens=False)["input_ids"]; serializations: sha256 / blake2b of json.dumps(ids),
# of " ".join(map(str, ids)) and of struct.pack(f"<{len(ids)}i", *ids), each hexdigest()[:16]
```

```python
# resplit.py (core): post-hoc single adjacent-pair re-splits, same bytes, scored by the record's ids_sha
toks = tok.convert_ids_to_tokens(ids); vocab = tok.get_vocab()
for i in range(len(ids) - 1):
    s = toks[i] + toks[i + 1]
    for k in range(1, len(s)):
        a, b = s[:k], s[k:]
        if (a, b) != (toks[i], toks[i + 1]) and a in vocab and b in vocab:
            alt = ids[:i] + [vocab[a], vocab[b]] + ids[i + 2:]
            if hashlib.sha256(json.dumps(alt).encode()).hexdigest()[:16] == r["ids_sha"]: found.append((i, a, b))
```
