## 5. Traps

1. **No scipy anywhere on this laptop.** Build a throwaway venv in the
   session scratchpad; never install into the user's miniconda base.
2. **Two untracked design handoffs sit in the tree**
   (`HANDOFF-2026-08-22-design.md`, `HANDOFF-2026-08-23-design.md`) and
   **MUST NOT be committed** — they say so in their own headers. A
   `git add -A` would publish them.
3. **`git commit` commits the whole index.** Stage explicitly *and* check
   `git diff --cached --name-status` first.
4. **Never seed from `hash()` on a str** — it is salted per process and made
   the cached gate unreproducible across two runs. Use
   `valence_core.discrim.seed_for` (crc32).
5. **A stub that returns zeros looks like a passing smoke.** The selftest
   stub silently produced zero concept vectors and zero instrument variance
   until its residuals were made sequence-sensitive. Read the number, not the
   exit code.
6. **Rate measurements need realistic prefixes.** The cached gate read 1.07×
   at ~50-token transcripts and 1.85× at 370 — B3's real length. Same
   hardware.
7. **`data/configs/` and `data/olmo/*.npz` are explicit gitignore
   allowlists.** A new config or npz is silently dropped from a commit unless
   named in `.gitignore`. This has bitten twice.
8. **Backticks in `git commit -m` trigger shell substitution.** Use
   `-F -` with a heredoc.
9. The box cannot reach GitHub (private repo, no credentials). Sync with
   `git bundle create` + `scp` + `git pull --ff-only <bundle> main`.
10. The `box` ssh alias goes stale on every pod respawn; the live endpoint is
    in the RunPod MCP `list-pods` output under `ssh.direct`.
