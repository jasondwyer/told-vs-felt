**2.3 Dose — `corrupt_m`, fixed at rate 0.15.** Per-item rng `default_rng(crc32(f"corr|{i}") % 2**31)` (f1's key; `i` 0-based). Eligible positions: letters a–z or A–Z that do not begin a word. One `permutation` of them; walk in order; **each slot consumes exactly one replacement draw, accepted or skipped; no draw depends on k**. Replacement: `chr(ord('a') + ((ord(orig.lower()) - ord('a') + 1 + rng.integers(25)) % 26))` — lowercase, never the original. Skip: after applying the replacement to the render as it stands with all earlier accepted replacements, if the render contains a roster word of either roster as a case-insensitive substring, the slot is skipped and the walk continues. k = clip(floor(0.15·n_eligible + 0.5), 3, floor(n_eligible/2)); n_eligible per item (0–15): 6, 19, 19, 13, 24, 16, 10, 45, 19, 10, 24, 15, 6, 19, 10, 17 ([C]); k per item: 3 3 3 3 4 3 3 7 3 3 4 3 3 3 3 3.
