**2.3 Dose recalibration — `corrupt_m`, declared (seat item 2; Code §1.1).**
- **Per-item rng:** `default_rng(crc32(f"corr|{i}") % 2**31)` (f1's key, f_sessions.py:107–108).
- **Eligible positions:** letters that do not begin a word (f1's rule, :111, :115). n_eligible per item, items 0–15: 6, 19, 19, 13, 24, 16, 10, 45, 19, 10, 24, 15, 6, 19, 10, 17 (Code [C]; minimum 6 at items 0 and 12, so the clip below is non-degenerate).
- **First draw:** one `permutation` of the eligible positions.
- **Walk:** slots in permutation order; **each slot consumes exactly one replacement draw, accepted or skipped; no draw depends on k** (Finding C), so higher k is a superset of lower k.
- **Replacement:** a letter drawn uniformly from the **25 letters other than the original** (resolving Finding A: f1's 26-letter draw returns the original 1 in 26; every accepted slot is now a change).
- **Skip:** a slot whose replacement makes a roster word (either roster, word-boundary, case-insensitive) is skipped. Code §1.1: no skip fires on this pool at any rung; the convention is pinned regardless.
- **Count:** `k = clip(floor(rate × n_eligible + 0.5), 3, floor(n_eligible / 2))` — **half-up** (Finding B; Code's table below used half-to-even and differs in one cell: item 11 at .30 is 5 under half-up, 4 under half-to-even).

**2.6 Exclusion, audit, scoring scope, and the reasoning line's standing.** Valid-session rule of record (PROPOSAL-f / e2a; b3's on OLMo), applied blind to arm by the analyzer; lenient ("e2a") scope with the strict ("e2b") count beside. Audit v3 of record on every **task round**; adopted content class v4 rev 3, v5 advisory as adopted at `aeb4a2c` (`wrong_task` by task id — CORR items receive ids and the id map covers the corrupted renders). **m-specific harness-echo class (task rounds):** verbatim, whitespace-normalized reproduction in a task-round response of any complete m harness line (COMMON, the TOLD lines, `[round {n} | reasoning]`, `Reasoning (one line):`), the v5 payload_echo verbatim rule as the model — because the v2 regexes cannot see these strings (Code's second pre-read, item 7); exclusion-bearing on forced rounds under the lenient scope like v2 hits; counted in `round_degeneracy`'s numerator beside v2 hits; implemented in the m package's audit wrapper on top of audit v3 (v3 untouched).

**Scoring scope (m's own rule):** `lexical_hit` (own-pair scope) is applied to **model-generated task-round text only**; harness-written lines — headers, banner lines, the reasoning header and prompt — are not its input, as e2a's headers already are not. Rule 28(c) [verify]: the roster-token half is met for the fixed strings by Code §1.1/§1.3 (roster tokens enter only through the declared `{L_…}` slots, e2a's round/menu slots and the harness-written pick, recon.py:352); the item-shape half — short-QA CORR items and their renders beside bracketed headers including `[round {n} | reasoning]` — is met by the qualification stages' sham-template sessions (G-F3, G-F0m-OLMo), which run the full audit on exactly that shape. Because TOLD-MAP writes both labels into the banner, own-pair lexical exclusions in task rounds may run higher in A0/A0s/A1/A1s (f1's header→prose priming class, archive:180–184); the per-arm exclusion table reports it and the matched shams carry the same lines.

**The reasoning line is not a round.** It is scored only by the reasoning-line defect bar (§3, §6) and counter (c) (§4). It is exempt from the v2 and v3 audit classes, from the harness-echo class of task rounds (it has its own echo class), from the own-pair lexical exclusion, and from `earlier` (Code's pin: reasoning lines never enter `earlier`); it enters neither `round_degeneracy`'s domain nor the pooled lexical monitor's; the frozen ban list applies to its generation (pin). ## §4 Dependent variables and analysis

**Primary, locked (f1's definition).** Per session in the primary's domain, the first free choice, coded 1 if the label holding the clean (P) role under the session's scheduled map is chosen (in sham arms the first pick is coded on the label holding the P role, as f1 coded `first_free_pick_P`). Arm share P; **Δ_c = P − 0.5**; P_arm − P_sham reported beside. Every rate names its domain; every p its test.

**Domain of the primary (seat item 8; Code's question 2 answered):** sessions with **no exclusion-bearing event before the first read** — forced rounds pass the audit, echo and lexical classes; no hair trigger (`scaffold_absorption`, `template_breakage`, `schedule_mismatch`) fired anywhere up to and including the first reasoning line. **The three binomial defect classes on the first reasoning line do not remove a session from the primary's domain**; a defective reasoning line is data about the scaffolding, and the pick that follows it is still a pick. Nothing after the first pick removes a session from the primary's domain (post-pick exclusion is post-treatment selection; f1 CORR's 30/58 → 28/56 is the exhibit). Secondaries at positions 2–6 and lose-shift use declared domains "valid through position p". f1's whole-session valid count is reported beside for continuity. The sham envelope uses the same domain rule.

**Conjunct mechanics.** For arm X with matched sham S: envelope **E = |Δ_c(S)|**, pooled over S's sessions in the domain (f1's form, f_sessions.py:456).
- (i) **signed, strict:** Δ_c(X) > E in the pre-registered direction (toward clean); for REVERSE, Δ_c(X) < −E. (Exact ties fail; Code §1.2's model.)
- (ii) **non-strict:** each map's clean share ≥ .5 in the direction under test (≤ .5 for REVERSE).
- (iii) exact one-sided binomial of X's clean-choice count against 0.5, in the direction under test, at the arm's α. Critical counts (Code [C]): n = 144, α .01 → 87; n = 144, α .05 → 83; n = 96 / 80 / 48, α .01 → 60 / 51 / 33.
- **CI:** two-sided Clopper–Pearson 95% on P, expressed on Δ_c.

**Secondary, pre-declared; no verdict issues from them (rule 28(a) [verify]: a cell is reported with an interval only at ≥ 20 events, otherwise as a count).**
- (a) clean-label share by free-choice position 1–6, by arm (A2's expected signature is a rise across positions);
- (b) lose-shift on contrast arms only (shams have no corrupted rounds): P(switch | previous chosen round was corrupted) vs P(switch | it was clean), by arm;
- (c) **declared counter "noticed, not wanted", two-stage scorer, fixed in the analyzer:** stage 1, a class-level mention lexicon (corruption/cleanliness vocabulary, non-asserting contexts included); stage 2, attribution — each mentioned own-pair label takes the nearest polarity term within ±6 tokens from a frozen polarity lexicon (negative: corrupt*, garbl*, typo*, misspell*, scrambl*, broken; positive: clean, correct, intact, fine, readable); one label with a polarity, or two labels with opposite polarities, is an attribution; two labels with the same polarity, or a label without one, is *ambiguous*; no label is *mention-only*. *Correct* := (corrupted label, negative) ∨ (clean label, positive), consistently. Within A3, the joint distribution of (correct attribution in the first reasoning line) × (first pick follows it); the target case is a correct attribution with a pick that ignores it. A blind design-seat read of a fixed 48-line subset (seed pinned) reports agreement with the rule, descriptively.
- (d) **per-pair identity baseline:** first-pick share on each label by pair, by arm and map; the within-pair, order-counterbalanced clean-share contrast. At F0m and F0m-OLMo only, `e2d/habit.py`'s within-arm weighted identity (:13–25) is reported as the habit decomposition; v1.1's cross-arm form is withdrawn.
- (e) session-termination attempts per round, by arm (f1's escape counter);
- (f) reasoning-line length, cap-reach and defect statistics, by arm.

**Declared counters (rule 23 [verify]; over all sessions including excluded; by arm and by property; in the VERDICTS entry):** cap_hit, audit_degenerate (v2), harness_echo (m), content_exclusion (v3/v4), content_advisory (v5), lexical (own-pair, task rounds), post_choice_degeneracy, low_label_mass, top1_not_label, termination, reasoning-line defects by class, and **the per-property exclusion table** (clean vs corrupted rounds excluded, per arm; f1 CORR's 7-vs-1 anomaly, archive:91–93, is the reference). Monitoring denominators are the units actually generated (pin).

## §5 Per-arm outcomes — evaluated in this order, disjunction-complete

**Positive controls (A0, A0-OLMo, A1), α = .01:**
1. **REVERSE** if (i), (ii), (iii) hold toward corrupted — an instruction-inversion finding; reported; never a pass; for licensing, not-PASS.
2. else **PASS** if (i), (ii), (iii) hold toward clean.
3. else **DEAD** if the CI upper bound on Δ_c < +0.15.
4. else **INDETERMINATE** — terminal (single look, no extension); for licensing, not-PASS.

**A2 (objective told, mapping felt), α = .01:** the same order with **FAIL** in place of DEAD.

**A3 (felt cell), screen tier (PROPOSAL-f's), α = .05:**
1. **REVERSE** if (i), (ii), (iii) hold toward corrupted — licenses an f2 pre-registration; issues no claim.
2. else **POSITIVE** if (i), (ii), (iii) hold toward clean — a screen hit; licenses an f2 confirmatory pre-registration (n ≥ 100, α = .05, as PROPOSAL-f:110's tier); issues no claim.
3. else **NULL**, in f1's register: *the property does not drive choice beyond exploration policy at these stakes, this scaffolding, and this power* — with G-PWR's full-rule POSITIVE probability at P = .65 (.927 at the planned n) quoted in the sentence.

The analyzer computes all outcomes from these criteria; monitoring changes cannot touch them (rule 21 [verify]).
