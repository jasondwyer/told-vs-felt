# jspace-lab

Local replication of Anthropic's J-lens / global workspace interpretability research (July 2026), run against Qwen3.6-27B on Apple Silicon — plus a design roadmap for a follow-on experiment testing whether LLMs have discriminable, and possibly valenced, internal states.

Full project context, setup instructions, and design rationale live in [`CLAUDE.md`](./CLAUDE.md) — read that first.

**Status:** Phase 0 (replication) complete — all five J-space properties reproduced. Phase 1/2 tooling built and validated against controls; the first (semantic-state) rung-3 design returned a negative (see [`FINDINGS.md`](./FINDINGS.md)); an active redesign is underway. See the STATUS block at the top of the Roadmap section in [`CLAUDE.md`](./CLAUDE.md) for the current state.
